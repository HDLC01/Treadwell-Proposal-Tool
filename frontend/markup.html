Kyle's markup chain, per sheet layout. The tabs are the five sheet tabs a bid can sit on — not work types, and there is no Combo, because a combo job is two option lines each priced off its own tab. The rows run in the order the chain compounds: each line's base is the running total of everything above it. A formula evaluates to a rate applied to that base; MARKUP() and a typed figure return dollars instead.
